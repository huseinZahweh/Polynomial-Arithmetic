Cryptographic applications

GF(2128)IEEE 1619

XTS-AES GF(2128) Tweak Multiplier

IEEE 1619-2007 / Stallings Ch. 6 disk sector encryption masks each 128-bit block using Cj = EK1(Pj ⊕ Tj) ⊕ Tj, advancing the tweak by Tj = T0 ⊗ αj mod (x128 + x7 + x2 + x + 1). Whenever the top bit b127 = 1, shifting left overflows x128 and triggers an XOR with 0x87.

Sector tweak sequence

Polynomial / Binary Elliptic Curve (E2m(a,b)) Explorer

Stallings Ch. 10 & NIST FIPS 186-4 / SEC 2 non-supersingular binary curves satisfy y2 + xy = x3 + ax2 + b modulo irreducible polynomial m(x) (coefficients a and b, as well as x and y, are polynomials in GF(2m)). Every point doubling (R = 2P), point addition (R = P + Q), and ECDH scalar multiplication runs directly on our finite-field engine (⊕, Shift-and-XOR ×, and Extended Euclid ÷).

Curve parameters & group operations

GCM · GHASH Authenticator (GF(2128))

Stallings Ch. 12 / NIST SP 800-38D Galois/Counter Mode computes a 128-bit authentication tag over ciphertext and AAD blocks as Ym = (X1 · Hm) ⊕ (X2 · Hm-1) ⊕ ... ⊕ (Xm · H), evaluated iteratively via Yi = (Yi-1 ⊕ Xi) · H mod (x128 + x7 + x2 + x + 1) using our full 128-bit XOR and Shift-and-XOR multiplication engine.

.txt Format

Use A: and optional B: lines, # comments, and --- or === separators between pairs.

# Comment lines start with #
A: 57
B: 83
---
# B is optional for Reduce (mod) or Inverse

.json Format

Provide a "pairs" array with "a", optional "b", and "base" ("hex", "bin", or "algebraic").

{
  "pairs": [
    { "a": "57", "b": "83", "base": "hex" },
    { "a": "10010101", "base": "bin" }
  ]
